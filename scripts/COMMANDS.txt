VANPICS — PORTFOLIO UTILITY COMMANDS
─────────────────────────────────────────────────────────────────────────────

1. LOCAL DEVELOPMENT SERVERS
   ─────────────────────────
   - npm run dev -- --host
     (Starts the Vite dev server and makes it accessible on your local network)

   - py -m http.server 5173 --bind 0.0.0.0
     (Python fallback server on port 5173, accessible to other devices)

   - npm run build
     (Optimizes the site and creates a 'dist' folder for final production)


2. DATA & MAINTENANCE SCRIPTS
   ──────────────────────────
   - npm run sort
     (Sorts js/data/photos.js newest to oldest. Undated photos move to bottom + alphabetical)

   - node scripts/generate-photos.js
     (Converts big images from /photos-raw to .webp (70% quality) into /photos)

   - node scripts/add-ratios.js
     (Scans your photos and adds / updates 'aspectRatio' in js/data/photos.js to kill CLS)

   - node scripts/generate-thumbs.js
     (Generates thumbnails for the gallery, filmstrip, and lightbox blur)


3. BROWSER UTILS & PATCHES
   ────────────────────────
   - scripts/firefox-patch.js
     (Integrated Firefox performance patch: kills WebGL blur overhead, pauses hero/glow loops, thumbnail hand-off)


─────────────────────────────────────────────────────────────────────────────
NOTE: Run these from the project root directory.
